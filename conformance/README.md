# Conformance vectors

Language-neutral test cases for the strict profile of Always Pathway v0.2.
Every value is synthetic and derived from the upstream example file.

`manifest.json` lists each vector:

```json
{
  "file": "vectors/response-13-14-self.json",
  "kind": "response",
  "description": "Under 15 consenting alone, with no parental confirmation.",
  "options": { "now": "2026-11-01T00:00:00Z" },
  "expect": { "valid": false, "codes": ["PW102"] }
}
```

- `kind` is one of `organisation`, `response`, `event`, `handoff`
  (`{response, receiver}`), `stream` (an array of events) or `bundle`
  (`{organisation?, response?, event?}`).
- `options` may set `profile` (`strict` default, or `base`), `sending`
  (default `true`), `now`, `maxConsentAgeDays` and `complete`.
- `expect.codes` is the exact set of distinct issue codes a conforming
  validator reports; `expect.valid` is false when any is error-severity.

An implementation in another language conforms if, for every vector, it
reports exactly `expect.codes`. Paths and messages are not compared.

Vectors are generated by `scripts/generate-vectors.py`; edit that, not the
JSON, and re-run it from the repository root.
